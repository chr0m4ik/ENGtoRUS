# TRANSLATOR.EXE
### Преобразователь раскладки текста

Простая утилита для смены раскладки или регистра у текста.

---
<div align="left">

## ФУНКЦИИ
- **Смена раскладки текста** (доступно: английский, русский) 
- **Смена регистра текста**
- **Копирование результата в буфер обмена**

## ИСПОЛЬЗОВАНИЕ
При запуске программы выберите один из двух режимов:
1. **Смена раскладки**
2. **Смена регистра**

Затем введите текст для получения исправленного результата.

> **Примечание:** Не работает с многострочным текстом.
